# MDSLC Compiler Archaeology Findings Index

This directory contains the scientific findings and comparative architectural analysis generated by the Windows Lowering Corpus investigation across **LLVM/MLIR 20.1.8, 21.1.8, and 22.1.8**.

## Findings Index

| Document | Focus Area | Primary Architectural Questions Answered |
| :--- | :--- | :--- |
| [lowering-invariants.md](lowering-invariants.md) | **Cross-Version Lowering Invariants** | What compiler transformations, loop vectorization rules, and dialect lowerings remain invariant across LLVM 20, 21, and 22? |
| [version-deltas-20-21-22.md](version-deltas-20-21-22.md) | **Differential Version Analysis** | What changed between LLVM 20, 21, and 22? Which changes are mere API/helper churn vs. true semantic shifts? |
| [semantic-loss-atlas.md](semantic-loss-atlas.md) | **Semantic Loss Atlas** | Exactly where and at which lowering boundary do shapes, memory spaces, aliasing, alignment, and numerical contracts disappear? |
| [matcore-boundary-findings.md](matcore-boundary-findings.md) | **Matcore Architectural Boundary** | Clear separation of responsibilities: **WHAT** (Matcore semantic MLIR) vs. **HOW** (Upstream planning/scheduling) vs. **MACHINE** (Target code/LLVM). |
| [upstream-mlir-findings.md](upstream-mlir-findings.md) | **Upstream MLIR Transformation Surface** | Canonical lowerings for `linalg.matmul`, `scf.forall`, `vector.contract`, One-Shot Bufferization, and GPU dialects. |
| [cpu-findings.md](cpu-findings.md) | **CPU Native Lowering & Microkernels** | FMA formation, register tiling, AVX2 vs. AVX-512 code generation, and alignment preconditions. |
| [nvidia-findings.md](nvidia-findings.md) | **NVIDIA / NVVM Surface Archaeology** | Open CUDA/NVGPU patterns, `mma.sync.m16n8k16`, `cp.async` staging, and `ldmatrix` fragment layouts. |
| [amd-findings.md](amd-findings.md) | **AMD / ROCDL Surface Archaeology** | Open HIP/AMDGPU patterns, `amdgpu.mfma`, and LDS memory buffering. |
| [schedule-knowledge.md](schedule-knowledge.md) | **Schedule Knowledge Base** | Empirical schedule parameters (tile sizes, register blocking, pipeline stages) mapped to upstream MLIR concepts. |
| [evidence-gaps.md](evidence-gaps.md) | **Explicit Evidence Gaps** | Documented limitations, hardware-unavailable lanes, and external toolchain boundaries. |
